# ユーザーガイド: Peer-to-Peer同期（2026年版）

Peer-to-Peer（P2P）同期は大きく進化しました。このガイドでは、基本的な設定方法と、2026年の更新で導入された新機能を説明します。

## 1. 基本概念: サーバーなしの自由

P2P同期では、WebRTCを使ってデバイス同士が直接通信します。データ保存用の中央サーバーは不要で、プライバシーと自由度を高く保てます。

## 2. P2P状態ペインから設定する

複雑なメニューをたどる必要はありません。リボンアイコンまたはコマンドパレットから **P2P状態** を開き、**歯車** アイコンをクリックします。

**P2P設定** ダイアログが開き、次の基本項目を設定できます。

- **ルームID:** 同期グループを識別する一意のIDです。
- **パスフレーズ:** 暗号化キーです。すべてのデバイスで完全に同じパスフレーズを使用してください。
- **デバイス名:** 現在のデバイスを識別しやすい名前です。例: `iphone-16`

`0.25.64` から、P2Pには通常のデータベースレプリケーション用リモートとは別に、P2P専用の有効リモート選択があります。歯車アイコン横のコンボボックスで、P2P機能に使用するリモート設定を選択してください。

P2P用リモートがまだない場合は、**+** ボタンからP2P設定ダイアログを開き、専用のP2Pリモート設定を作成できます。P2Pの同期対象や監視設定を保存するには、有効なP2Pリモートの選択が必要です。

設定を保存したら **P2P状態ペイン** に戻り、**接続** ボタンをクリックしてネットワークへ参加します。

ヒント: 設定ダイアログで **自動接続** を有効にすると、Obsidian起動時に自動でネットワークへ参加できます。

## 3. リアルタイム制御

右サイドバーの状態ペインでは、同期を細かく制御できます。

- **シグナリング状態:** リレーに接続されているかを表示します（オンライン時は緑の表示）。
- **ルームID接尾辞:** ピアIDの上に、安定して識別しやすいルームIDの末尾が表示されます。ピアIDは接続ごとに変わることがありますが、ルームID接尾辞はP2Pグループの確認に役立ちます。
- **ライブ送信:** 「ピアへライブ送信」を有効にすると、編集時に他のピアへ変更を通知します。
- **今すぐレプリケーション:** 表示されているピアと即時に双方向レプリケーション（取得してから送信）を開始できます。
- **監視:** 特定のピアで「監視」を有効にすると、そのピアが変更を通知したときに自動で取得します。LiveSyncに近い体験になります。
- **同期対象:** 特定のピアを同期対象にできます。対象にしたピアは、**P2P: 対象と同期** コマンドの実行時にまとめて同期されます。ピア横のボタンでオンまたはオフを切り替えられ、この設定は構成に保存されます。

## 4. レプリケーションダイアログ

特定のピアと手動で同期したい場合は、レプリケーションのコマンドまたはボタンを使用します。利用可能なデバイスを一覧表示する **レプリケーションダイアログ** が開きます。

ダイアログ上部の **サーバー状態** カードでは、同期中も接続状態を確認できます。状態カードにはピアIDに加えてルームID接尾辞も表示されます。

各ピアでは次の2つの操作を使用できます。

- **同期**: 双方向同期（取得してから送信）を開始します。ダイアログは開いたままなので、進行状況を確認したり、追加のピアと同期したりできます。
- **同期を開始して閉じる**: 同じ双方向同期をバックグラウンドで開始し、すぐにダイアログを閉じます。待たずに作業を続けられます。

## 5. コマンドパレットから登録済み対象と同期する

UIを開かずに、登録済みの対象ピアすべてと一度に同期できます。

1. **コマンドパレット**（`Ctrl/Cmd + P`）を開きます。
2. **P2P: 対象と同期** を実行します。

このコマンドは、**検出されたピア** 一覧で **同期対象** が有効になっているすべてのピアと同期します。対象が登録されていない場合や、P2Pサーバーが起動していない場合は通知が表示されます。

ヒント: このコマンドにホットキーを割り当てると、キーボードだけで素早く同期できます。

## 6. 2026年の技術的改善

- **分離されたアーキテクチャ:** UIとコアロジックが明確に分離され、モバイル、デスクトップ、Webなど異なる環境でより安定しました。
- **Svelte 5 UI:** 応答性が高く、状態を把握しやすいインターフェースに再構築されました。
- **セキュリティ:** データは常にエンドツーエンドで暗号化されます。シグナリングリレーも実際のノート内容を見ることはありません。
